# Template Repo for Classic MBed via PlatformIO

This repo contains template code and configuration for writing ARM Mbed programs on an STM32 L476RG Nucleo microcontroller using the PlatformIO toolchain.

For a tutorial on development environment setup, see the [setup docs](docs/setup.md).

To use this template, create a new repository on GitHub.com and select this repo (*DevonLantagne/mbed-pio-template*) as the template.
